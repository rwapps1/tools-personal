🎙️ Podcast Voice Generator

Paste or upload a script, pick a voice, tap Generate. Everything runs on this device — the voice model downloads once (first use only) and is cached after that.

⬇️ Download WAV file

First generation on a new device downloads a ~90MB voice model over your normal internet connection, so use Wi-Fi if you can. After that it's cached in this browser and later runs are quick. The very first sentence generated each session is also the slowest — the speech engine is warming up — after that each part should speed up noticeably. If your device supports it this uses GPU acceleration (fast); otherwise it falls back to CPU-only mode, which can take a couple of minutes per part on an older phone — the status line shows which mode is active and a running timer, so it should never look frozen. Nothing you type or upload is sent anywhere — it all happens locally in this tab.
