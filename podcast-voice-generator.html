🎙️ Podcast Voice Generator

Paste or upload a script, pick a voice, tap Generate. Everything runs on this device — the voice model downloads once (first use only) and is cached after that.

⬇️ Download WAV file

First generation on a new device downloads a ~90MB voice model over your normal internet connection, so use Wi-Fi if you can — that part is cached after the first time. But starting the speech engine itself is a separate step that is not cached — it happens fresh every time you reload this page, and on some phones can take a few minutes with no progress shown by the browser itself (the status line ticks a timer so you can see it's still alive). This runs in CPU-only mode deliberately — GPU mode was faster but produced audible glitches on-device. Once it's running, generating each part of the script is much quicker. Nothing you type or upload is sent anywhere — it all happens locally in this tab.
